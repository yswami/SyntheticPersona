# Roadmap

## v0.1 - Public toolkit foundation

- [x] Constraint-based enterprise PPM reviewer prompt
- [x] Hypothetical step-by-step PPM scenario
- [x] Illustrative simulated output
- [x] Evidence repository template
- [x] Evidence-backed archetype card
- [x] Method and responsible-use guardrails

## v0.2 - GitHub Pages learning experience

- [ ] Guided feature and context form
- [ ] Behavioral-constraint configurator
- [ ] Live, local prompt preview
- [ ] Preloaded PPM example
- [ ] Copy and download actions
- [ ] Three-question trust-test explanation
- [ ] Clear hypothesis-versus-evidence labeling
- [ ] Mobile and accessibility verification

The first web version will be static and privacy-conscious. It will not store inputs, accept API keys, or send prompts to a model.

## Later experiments

- Evidence register import with local-only processing
- Archetype-card builder with evidence completeness checks
- Side-by-side comparison of simulated and human-validated findings
- Versioned prompt and model-run metadata
- Additional fictional enterprise scenarios

Any live model integration would require an explicit privacy model, abuse controls, cost controls, data-retention policy, and clear user consent.
